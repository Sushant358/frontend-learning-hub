CSS LEARNING PATH

1. Getting started with CSS

CSS (Cascading Style Sheets) controls how HTML looks: colors, spacing, typography, layout, animation, and responsive behavior.

/* External stylesheet */
h1 { color: royalblue; }
.card { padding: 1rem; border-radius: 12px; }

/* Connect CSS to HTML inside <head> */
<link rel="stylesheet" href="style.css">
CSS LEARNING PATH

2. CSS syntax and selectors

A CSS rule contains a selector and a declaration block. Selectors choose the HTML elements to style.

/* Element, class, and ID selectors */
p { line-height: 1.6; }
.card { padding: 16px; }
#main-title { color: navy; }

/* Grouping, descendant, child, attribute, pseudo-class */
h1, h2 { font-family: system-ui; }
nav a { text-decoration: none; }
ul > li { margin-block: 6px; }
input[type="email"] { border-color: teal; }
button:hover { transform: translateY(-2px); }
a:focus-visible { outline: 3px solid orange; }
CSS LEARNING PATH

3. Cascade, inheritance, and specificity

When declarations conflict, CSS resolves them using origin, importance, cascade layers, specificity, and source order. Some properties inherit from parents.

/* Prefer simple selectors and predictable source order */
:root { color: #182033; }
body { font-family: system-ui, sans-serif; }
.card { color: #334155; }
.card strong { color: #111827; }

/* Avoid overusing !important */
.notice { color: crimson; }

4. Colors, values, and units

Use suitable units: px for fine details, rem for scalable typography and spacing, %, vw/vh for relative sizing, and fr for grid tracks.

:root {
  --brand: #4f46e5;
  --space: 1rem;
}
.box {
  width: min(90%, 70rem);
  padding: var(--space);
  font-size: 1rem;
  color: #172033;
  background: rgb(79 70 229 / 10%);
  border: 1px solid hsl(230 20% 85%);
}

5. The box model

Every element is a box: content, padding, border, and margin. `box-sizing: border-box` makes declared dimensions include padding and border.

* { box-sizing: border-box; }
.card {
  width: 300px;
  padding: 20px;
  border: 1px solid #ddd;
  margin: 16px 0;
}
CSS LEARNING PATH

6. Typography and text

Control font family, size, weight, line height, letter spacing, alignment, and text decoration. Keep body text comfortable to read.

body { font-family: Inter, system-ui, sans-serif; }
h1 { font-size: clamp(2rem, 5vw, 4rem); line-height: 1.1; }
p { max-width: 65ch; line-height: 1.7; }
.small { font-size: .875rem; font-weight: 600; }

7. Backgrounds, borders, and shadows

CSS supports solid colors, gradients, background images, border styles, rounded corners, outlines, and shadows.

.hero {
  background: linear-gradient(120deg, #312e81, #0891b2);
  color: white;
  border-radius: 1.25rem;
  box-shadow: 0 12px 30px rgb(15 23 42 / 15%);
}

8. Display and positioning

`display` controls layout behavior. Positioning options include static, relative, absolute, fixed, and sticky. Use these intentionally.

.hidden { display: none; }
.inline-item { display: inline-block; }
.badge { position: relative; }
.tooltip { position: absolute; inset-block-start: 100%; }
.site-nav { position: sticky; top: 0; z-index: 10; }
CSS LEARNING PATH

9. Flexbox

Flexbox is ideal for one-dimensional layouts: arranging items in a row or column and distributing available space.

.toolbar {
  display: flex;
  align-items: center;
  justify-content: space-between;
  gap: 1rem;
  flex-wrap: wrap;
}
.actions { display: flex; gap: .5rem; }
CSS LEARNING PATH

10. CSS Grid

Grid is designed for two-dimensional layouts with rows and columns. Combine it with `minmax()` and `auto-fit` for responsive grids.

.cards {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(220px, 1fr));
  gap: 1rem;
}
.dashboard {
  display: grid;
  grid-template-columns: 240px 1fr;
  grid-template-areas: "sidebar content";
}

11. Responsive design and media queries

Responsive design adapts content to different screen sizes. Start with flexible layouts, then add breakpoints when the content needs them.

img { max-width: 100%; height: auto; }
.container { width: min(100% - 2rem, 1100px); margin-inline: auto; }

@media (max-width: 700px) {
  .dashboard { grid-template-columns: 1fr; }
  .desktop-only { display: none; }
}
CSS LEARNING PATH

12. Transitions, transforms, and animations

Transitions smooth changes between states. Transforms move, rotate, scale, or skew elements. Keyframes define multi-step animations.

.button { transition: transform .2s ease, background .2s ease; }
.button:hover { transform: translateY(-2px); }

@keyframes pulse {
  0%, 100% { transform: scale(1); }
  50% { transform: scale(1.04); }
}
.pulse { animation: pulse 1.5s infinite; }
CSS LEARNING PATH

13. Custom properties and functions

CSS variables make themes and repeated values easier to maintain. Useful functions include `calc()`, `min()`, `max()`, and `clamp()`.

:root {
  --surface: white;
  --text: #172033;
  --accent: #4f46e5;
}
.panel { background: var(--surface); color: var(--text); }
.title { font-size: clamp(1.8rem, 4vw, 3rem); }
.wide { width: min(100% - 2rem, 72rem); }

15. Accessibility and best practices

Keep visible focus indicators, sufficient contrast, readable text, and reduced motion support. Never use CSS alone to communicate important meaning.

button:focus-visible, a:focus-visible {
  outline: 3px solid #f59e0b;
  outline-offset: 3px;
}
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    scroll-behavior: auto !important;
    animation-duration: .01ms !important;
    transition-duration: .01ms !important;
  }
}

16. Practice project: responsive profile card

Build a profile card with a portrait, short bio, and action links. Make it work on mobile and desktop, and test keyboard focus.

<article class="profile-card">
  <img src="avatar.jpg" alt="Portrait of Alex">
  <div>
    <h2>Alex Morgan</h2>
    <p>Frontend developer learning CSS.</p>
    <a href="#projects">View projects</a>
  </div>
</article>

.profile-card {
  display: flex;
  align-items: center;
  gap: 1rem;
  padding: 1.25rem;
  border-radius: 1rem;
  background: white;
}
.profile-card img { width: 96px; aspect-ratio: 1; border-radius: 50%; object-fit: cover; }
@media (max-width: 480px) { .profile-card { flex-direction: column; text-align: center; } }
