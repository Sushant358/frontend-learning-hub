# Connected Web Development Handbooks

Open `index.html` to start.

## Files
- `index.html` — HTML handbook
- `css.html` — CSS handbook
- `javascript.html` — JavaScript handbook
- `style.css` — shared stylesheet used by all three pages
- `script.js` — shared JavaScript used by all three pages

Keep all five files in the same folder. Open `index.html` in your browser. No installation is required.

## How they connect
Each HTML page loads `style.css` with a `<link>` tag and `script.js` with a `<script defer>` tag. The top navigation links all three handbooks together.
