1. Getting started with HTML

HTML means HyperText Markup Language. It defines the structure and meaning of web content. HTML is a markup language, not a programming language.

HTMLStructure and content
CSSAppearance and layout
JavaScriptBehavior and interaction

Your first web page

  1. Open a text editor, such as Notepad or VS Code.
  2. Write the code below.
  3. Save it as index.html.
  4. Open the file in a web browser.
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>My First Page</title>
</head>
<body>
  <h1>Hello, world!</h1>
  <p>I am learning HTML.</p>
</body>
</html>
Most elements use an opening tag, content, and closing tag. Void elements such as img, br, hr, and input do not have closing tags.

2. HTML document structure

Element / declarationPurpose

<head>Holds metadata, title, and resource links.
<meta charset="UTF-8">Sets character encoding.
<meta name="viewport"...>Helps the layout work on mobile devices.

  • https://example.com/page — an absolute URL.

6. Images and responsive images

<img src="images/cat.jpg" alt="A cat resting on a sofa" width="600" height="400">

<!-- Figure with caption -->
<figure>
  <img src="mountains.jpg" alt="Snowy mountains at sunrise" width="800" height="500">
  <figcaption>Sunrise in the mountains.</figcaption>
</figure>

<!-- Browser chooses a suitable image size -->
<img
  src="photo-800.jpg"
  srcset="photo-400.jpg 400w, photo-800.jpg 800w, photo-1200.jpg 1200w"
  sizes="(max-width: 600px) 100vw, 800px"
  alt="A person cycling on a trail"
  width="800" height="533"
  loading="lazy">

<!-- Art direction for different screens -->
<picture>
  <source media="(max-width: 600px)" srcset="portrait-small.jpg">
  <img src="landscape-large.jpg" alt="A landscape at sunset">
</picture>
Write useful alt text for meaningful images. Use alt="" for purely decorative images so screen readers can skip them. Set image dimensions to reduce layout shifts.

7. Audio and video

<audio controls preload="metadata">
  <source src="audio/song.mp3" type="audio/mpeg">
  Your browser does not support audio.
</audio>

<video controls width="640" poster="preview.jpg" preload="metadata">
  <source src="video/demo.mp4" type="video/mp4">
  <track kind="captions" src="captions-en.vtt" srclang="en" label="English">
  Your browser does not support video.
</video>

Provide captions for speech and meaningful sounds. Avoid autoplaying sound; browser policies and user experience make it unreliable.

8. Tables

<table>
  <caption>Student marks</caption>
  <thead>
    <tr><th scope="col">Name</th><th scope="col">Marks</th></tr>
  </thead>
  <tbody>
    <tr><th scope="row">Asha</th><td>88</td></tr>
    <tr><th scope="row">Ravi</th><td>91</td></tr>
  </tbody>
  <tfoot>
    <tr><th scope="row">Average</th><td>89.5</td></tr>
  </tfoot>
</table>

Use tables for tabular data, not for page layout. Use scope to associate header cells with rows or columns.

Common input types

HTML validation improves usability but is not security. A real application must validate and sanitize submitted data on the server. A form also needs a working server endpoint to submit data.

<!-- Embed another page; only use trusted sources -->

  src="https://example.com"
  title="Example website"
  width="600" height="400"
  loading="lazy"
  sandbox>
</iframe>

<!-- External scalable vector graphic -->
<img src="logo.svg" alt="Company logo" width="160" height="50">

<!-- External document -->
<object data="document.pdf" type="application/pdf" width="600" height="500">
  <a href="document.pdf">Open the PDF</a>
</object>
Embedding third-party pages may be blocked by their security policy. Use iframe sandbox permissions carefully, and never embed untrusted content without considering security and privacy.

15. Metadata, SEO, and resource links

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Useful Page Title | Site Name</title>
  <meta name="description" content="A concise, accurate page summary.">
  <link rel="canonical" href="https://example.com/page">
  <link rel="icon" href="/favicon.ico">
  <link rel="stylesheet" href="styles.css">
  <script src="app.js" defer></script>
</head>
  • Give each page a unique, descriptive title.
  • Write a clear description that accurately summarizes the page.
  • Use a canonical URL only when appropriate and correct.
  • Use meaningful headings and descriptive link text.
  • Use structured data only when it accurately represents visible page content.
Metadata can help browsers and search engines understand a page, but it does not guarantee a particular ranking or search-result appearance.

16. Accessibility essentials

  • Set the correct page language using lang.
  • Use semantic elements and a logical heading hierarchy.
  • Give form fields visible labels connected with for and id.
  • Provide meaningful alternative text for informative images.
  • Make sure interactive controls can be used with a keyboard.
  • Use descriptive link text instead of repeated “click here”.
  • Use ARIA when necessary, and prefer native HTML semantics when available.
  • Do not communicate meaning through color alone.
  • Use captions for video and transcripts when useful for audio.
<label for="search">Search articles</label>
<input id="search" name="q" type="search">

<button type="button" aria-expanded="false" aria-controls="menu">
  Toggle menu
</button>
<nav id="menu" aria-label="Main navigation">...</nav>

<p role="status" aria-live="polite">Saved successfully.</p>
ARIA attributes do not automatically add behavior. If you build a custom widget, implement its keyboard behavior, focus management, and state updates too.
LEVEL 3 · ADVANCED

17. Advanced HTML features

17.1 Template element

A template stores markup that is not rendered until JavaScript clones or inserts it.

<template id="card-template">
  <article class="card">
    <h2>Card title</h2>
    <p>Card description</p>
  </article>
</template>

<div id="cards"></div>
<script>
  const template = document.querySelector("#card-template");
  const clone = template.content.cloneNode(true);
  document.querySelector("#cards").append(clone);
</script>

17.2 Custom data attributes

<button data-product-id="p42" data-price="199">Add to cart</button>
<script>
  const button = document.querySelector("button[data-product-id]");
  console.log(button.dataset.productId); // "p42"
  console.log(button.dataset.price);     // "199" (string)
</script>

17.3 Defer and async scripts

<!-- Downloads in parallel, executes when ready; order not guaranteed -->
<script src="analytics.js" async></script>

<!-- Downloads in parallel, runs after parsing, preserves order -->
<script src="app.js" defer></script>

<!-- JavaScript module -->
<script type="module" src="main.js"></script>

17.4 Native lazy loading

<img src="gallery/photo.jpg" alt="Gallery scene" loading="lazy" width="800" height="600">
<iframe src="https://example.com/embed" title="Embedded content" loading="lazy"></iframe>

Use lazy loading for off-screen content, not usually for the main hero image that is immediately visible.

17.5 Responsive image sources

<picture>
  <source type="image/avif" srcset="hero.avif">
  <source type="image/webp" srcset="hero.webp">
  <img src="hero.jpg" alt="Description of the hero image" width="1200" height="700">
</picture>

17.6 Ruby annotations (often used for East Asian pronunciation)

<ruby>漢 <rp>(</rp><rt>かん</rt><rp>)</rp></ruby>

17.7 Bidirectional text isolation

<p>Username: <bdi>user_مثال</bdi></p>
<p><bdo dir="rtl">This text direction is overridden.</bdo></p>

17.8 Popover API

<button popovertarget="tip">Show tip</button>
<div id="tip" popover>This is a native popover.</div>

Modern browser support varies by feature. Check compatibility if your audience uses older browsers.

17.9 Details, summary, and dialog

details and summary provide a built-in disclosure widget. dialog provides a native dialog element; JavaScript typically opens it with show() or showModal().

17.10 Microdata (basic illustration)

<div itemscope itemtype="https://schema.org/Person">
  <span itemprop="name">Example Person</span>
</div>

Use structured data formats according to the needs of your project and the search engine documentation. Avoid adding misleading or hidden claims.

18. Obsolete or discouraged elements

Avoid old presentational HTML such as <font>, <center>, <marquee>, and layout tables. Use CSS for visual presentation and semantic HTML for structure.

Instead ofPrefer
<center>CSS text-align: center or layout styles
<font color="red">CSS color
Tables for layoutCSS Flexbox or Grid
<big>CSS font sizing or a semantically appropriate element

19. Practice project: personal portfolio page

Build a small portfolio using the concepts above. This example is intentionally simple so you can extend it with CSS and JavaScript later.

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>My Portfolio</title>
  <meta name="description" content="Projects and contact information.">
</head>
<body>
  <header>
    <h1>Your Name</h1>
    <p>Student · Web Developer · Designer</p>
    <nav aria-label="Main navigation">
      <a href="#about">About</a>
      <a href="#projects">Projects</a>
      <a href="#contact">Contact</a>
    </nav>
  </header>
  <main>
    <section id="about">
      <h2>About me</h2>
      <p>Write a short introduction about yourself.</p>
    </section>
    <section id="projects">
      <h2>Projects</h2>
      <article>
        <h3>Project One</h3>
        <p>Explain what you built and what you learned.</p>
        <a href="https://example.com">View project</a>
      </article>
    </section>
    <section id="contact">
      <h2>Contact</h2>
      <p>Email: <a href="mailto:you@example.com">you@example.com</a></p>
    </section>
  </main>
  <footer><p>&copy; 2026 Your Name</p></footer>
</body>
</html>

Suggested learning path

  1. Practice structure, text, links, images, and lists.
  2. Build accessible forms and data tables.
  3. Use semantic layout and responsive images.
  4. Learn CSS layout, typography, and responsive design.
  5. Add JavaScript for behavior, then learn browser APIs and performance.
  6. Test keyboard navigation, mobile layouts, and HTML validity.
